# Product Limitations (visible guardrails)

1. **Causal extraction remains unsolved** — mandatory human review and confidence scores.
2. **Semantic equivalence is contestable** — local expert sign-off required.
3. **Canonical artifacts may still identify sources** — `non-shareable` is first-class.
4. **Local ontologies go stale** — freshness warnings on every result.
5. **Agent evaluation is stochastic** — rates never without signed spec + cohort.
6. **Federated statistics can be gamed** — corroboration and confidence intervals shown.
7. **Mitigation may overfit** — negative controls and held-out variants mandatory.
8. **Cross-border governance is difficult** — jurisdiction fields in cohort eligibility.
9. **Network bootstrapping is hard** — local incident compiler is the entry product.
